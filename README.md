# 🧮 Dart Simple Calculator

A simple command-line calculator built using **Dart**. This project allows users to enter two numbers and choose a mathematical operation.

## ✨ Features

- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)
- Prevents division by zero
- Handles invalid operations

## 🛠️ Technologies Used

- Dart
- `dart:io` for user input and output

## 🚀 How to Run

1. Make sure Dart SDK is installed on your computer.
2. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

3. Navigate to the project folder:

   ```bash
   cd YOUR_PROJECT_FOLDER
   ```

4. Run the program:

   ```bash
   dart run main.dart
   ```

## 💻 Example

```text
Enter your num1: 10
Enter your num2: 5
Enter your operation (+, -, *, /): +
15
```
